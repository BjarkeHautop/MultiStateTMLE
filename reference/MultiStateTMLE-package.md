# MultiStateTMLE: Causal Inference for Multistate Event Processes via TMLE

Provides a framework for nonparametric causal inference with multistate
event processes, built around stochastic intensity interventions,
calibrated interventions, and composite estimands, and estimated using
targeted maximum likelihood estimation (TMLE) allowing flexible nuisance
parameter learning.
