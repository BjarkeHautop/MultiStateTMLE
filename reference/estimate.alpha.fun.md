# Search for the alpha achieving a target value (defunct)

`estimate.alpha.fun()` is defunct as of MultiStateTMLE 0.1.0. Use
[`calibrate_alpha()`](https://github.com/BjarkeHautop/MultiStateTMLE/reference/calibrate_alpha.md),
which solves for alpha internally.

## Usage

``` r
estimate.alpha.fun(...)
```

## Arguments

- ...:

  Ignored.

## Value

None; always errors.
